# fungeeee

**Status: In development**

Fungal species records and an underground fungal network are being developed for eeeearth local scenes. The work includes connections between nearby roots in test scenes. This public repository is a project summary; implementation and data are not published here.

Learn the science in the [Earth systems guide](https://github.com/eeeearth/eeeearth/tree/main/docs/earth-systems), or watch the [live stream](https://www.youtube.com/@jt55401/live). The simulation covers local scenes and does not model every Earth system.
